Welcome to my personal blog at [blog.anoj.net](https://blog.anoj.net).

I built this space as a dedicated home for long-form essays, field notes, and architectural patterns around AI agents, engineering, and systems.

### The Stack

- **Engine**: [Astro](https://astro.build/) — lightweight, zero JavaScript overhead by default, with native Markdown content collections.
- **Hosting**: GitHub Pages with automatic GitHub Actions deployment.
- **Custom Domain**: `blog.anoj.net` managed through Squarespace Domains with full HTTPS.
- **Agent Publishing**: Built-in script and frontmatter conventions allowing AI agents to draft and push new dispatches directly to production.
